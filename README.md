# Klasifikasi Cyberbullying Menggunakan CNN

Repository ini berisi kode penelitian berjudul “Klasifikasi Cyberbullying dan Regulasi Hukum Indonesia pada Interaksi Penggemar Idol K-Pop Menggunakan Convolutional Neural Network”.

## Tahapan Penelitian
1. Preprocessing teks
2. Pelabelan sentimen menggunakan InSet Lexicon
3. Penyaringan data bersentimen negatif menggunakan Dictionary-Based Classification
4. Pelatihan model CNN untuk mengklasifikasikan hate speech, flaming and harassment, dan denigration
5. Evaluasi model menggunakan metrik klasifikasi
6. Prediksi teks dan pemetaan hasil klasifikasi ke regulasi hukum Indonesia

## Dataset
Dataset disimpan di Google Drive. Pengguna perlu memiliki akses ke dataset dan menyesuaikan path file pada notebook.

## Cara Menjalankan
1. Buka notebook penelitian
2. Jalankan notebook menggunakan Google Colab
3. Hubungkan Google Drive
4. Sesuaikan path dataset
5. Jalankan sel kode secara berurutan


Catatan:
Hasil klasifikasi dan pemetaan regulasi hukum merupakan keluaran penelitian untuk keperluan akademik dan edukasi, bukan pengganti penilaian ahli atau nasihat hukum.
